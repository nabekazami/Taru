たるファイラー

Android 用のファイルマネージャー(個人で使うためのアプリ)

たるファイラーについて

たるファイラーは、作成者が自分の Android 端末で使うために作っているファイルマネージャーです。Google Play では配布していません。

1つのアプリで、次の場所のファイルを見たり、コピー・移動・削除などの操作をしたりできます。

  • 端末の内部ストレージ・SDカード
  • SFTP で接続するサーバー
  • Googleドライブ(複数のアカウント)

プライバシーポリシー

最終更新日: 2026年11月17日

1. 使う Google のデータ

Googleドライブを追加したときだけ、利用者の許可を得て、次のデータを使います。

  • Googleドライブのファイルとフォルダ(名前・種類・大きさ・更新日時・中身)
  • Google アカウントのメールアドレスと、ドライブの使用量・容量

許可の範囲は「Googleドライブのファイルの参照・編集・作成・削除」(https://www.googleapis.com/auth/drive)です。

2. データの使い方

  • ドライブのファイルの一覧を表示し、利用者が選んだ操作(開く・コピー・移動・名前の変更・削除など)を行うためだけに使います。
  • データは、利用者の端末と Google のサーバーの間で直接やりとりします。作成者や、ほかのサーバー・第三者には送りません。
  • 広告・分析・販売・人工知能の学習などには使いません。

3. 保存するもの

  • 端末の中にだけ、追加したアカウントのメールアドレスと、ドライブの使用量・容量を保存します。
  • Google のパスワードやアクセストークンは、このアプリでは保存しません(Google Play 開発者サービスが管理します)。
  • ファイルを開く・共有するときは、端末の中の一時ファイルの場所にダウンロードし、一定の期間が過ぎると自動で削除します。

4. 許可の取り消し・データの削除

  • アプリのドロワーで、Googleドライブのアカウントを長押しして「このアカウントを外す」を選ぶと、Google の許可を取り消し、保存したアカウントの情報を削除します。
  • Google アカウントの「サードパーティ製のアプリとサービス」からも、いつでも許可を取り消せます。
  • アプリをアンインストールすると、端末に保存した情報はすべて削除されます。

5. Google API サービスのユーザーデータに関するポリシー

たるファイラーが Google API から受け取った情報の使用と、ほかのアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。

6. 変更

このポリシーを変更するときは、このページを更新します。
